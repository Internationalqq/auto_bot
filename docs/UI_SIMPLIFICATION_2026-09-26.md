# Упрощение интерфейса Автобота — 26 сентября

Исходная версия AutoBot `8767d05`, CRM `1e22176`. До работы tracked CRM diff пустой; в AutoBot уже изменён `data/search_resume_checkpoint.json`. Этот файл и пользовательские `.impeccable/`, `.agents/`, `.codex/`, outputs сохранены. Текущий пакет — интерфейс смет, тендеров, поиска и оболочки CRM.

## Результат

Одна навигация «Сметы / Тендеры / База цен / Поиск позиции» на всех основных экранах. Убраны рекламный слоган, дубли заголовков/сводок и отдельная повторная кнопка результатов поиска над таблицей. Состояние и результаты доступны во вкладке поиска. Список смет показывает сумму, позиции и состояние каждой сметы; кнопка добавления в объект появляется при выборе строк.

Дополнительные фильтры, сведения о закупке и действия выбора строк раскрываются по нажатию. Настройка поиска в смете изначально свёрнута; существующий механизм раскрывает её при запуске/ошибке. Важная сверка источника при расхождении остаётся раскрытой. Убраны лишние тени, градиенты, вложенное оформление и завышенные размеры цифр. Оболочка CRM стала компактнее; загрузка, обновление и переход в отдельное окно сохранены.

Существующие URL/API, загрузка/проверка/выгрузки, фильтры, суммы, импорт CRM и подтверждение отправок не менялись. Данных об использовании для удаления целых функций нет: удалены дубли представления, а возможности сохранены. Параллельная задача поставщиков владеет отдельной вкладкой «Поставщики», buyer UI/API, фото и перепиской; её изменения выпускаются своим коммитом.
