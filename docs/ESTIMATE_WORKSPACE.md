# Карточка загруженной сметы

Действующий маршрут `/estimates/<id>` использует `templates/estimate_detail.html`,
`static/estimate_workspace.css` и `static/estimate_workspace.js`. Скрипт и стили
выдаются через `/estimates/workspace.js` и `/estimates/workspace.css`: этот префикс
проходит существующую авторизацию CRM в production. Нельзя заменять его прямым
публичным маршрутом без проверки Nginx. Внутренний порт AutoBot остаётся внутренним.

Карточка содержит оригинал и импорт в CRM, сводку со сворачиваемой сверкой,
поиск цен со статусом/журналом и единый блок вкладок с фильтрами и Excel.
Поиск использует выбранные типы позиций; текстовый запрос ограничивает таблицу.
Фильтры, экспорт и импорт сохраняют существующие URL. Для нулевого результата
фильтра показано пустое состояние, выгрузка скрыта. Разделы/итоги листов и
исходные единицы, включая масштабированные, остаются в таблице позиций.

`market_revision` — отпечаток времени изменения и размера двух сохранённых
рыночных файлов. Он снимается до чтения данных карточки. Опрос обновляет страницу
один раз после появления другой версии и завершения поиска; текст и типы в URL
сохраняются. Повторный неудачный поиск с прежними файлами не вызывает перезагрузку.
Наличие строк-заглушек не означает наличие отчёта. После перезапуска web-процесса
сохранённые файлы остаются доступными, хотя история выполнявшегося поиска пока
хранится в памяти. Этот пакет не делает рыночный исполнитель долговечным.

Вкладка источников и её Excel сохраняют найденные цены, в том числе кандидаты,
до применения фильтра доказательств. Строки сопоставляются с текущими позициями
через общий `match_market_rows`; неоднозначное совпадение не используется.
`NaN`/пустая ячейка не считаются найденным источником. Сравнение и экономика
по-прежнему получают только проверенные сопоставимые предложения. На странице
это различие подписано; найденная цена не является доказательством прибыли.

Оригинал `/estimates/<id>/original` выдаётся вложением с `private, no-store` и
`nosniff`, только для существующей записи и поддерживаемого файла внутри её
собственного каталога. Чужой каталог, символьная ссылка, неподдерживаемый или
отсутствующий файл дают 404. Рабочие данные не мигрируются. Откат этого выпуска
к предыдущему образу `8b40e20` совместим с хранилищем загруженных смет.

Импорт использует прежний capability и мост CRM: браузер получает локальный
payload чтением и передаёт его родителю для записи с текущими правами.
Без доступного объекта/явно включённого legacy-создания кнопка недоступна;
форма создания не появляется, когда этот сценарий выключен. Вкладки доступны
с клавиатуры, окно CRM удерживает фокус и закрывается Escape.

Проверки: `tests/test_estimate_workspace.py`, `tests/estimate_workspace_frontend_tests.js`,
существующие проверки выгрузок, scope notice, secure CRM bridge и общего рыночного
контракта. Полный прогон и фактические визуальные/production-проверки фиксируются
в CRM `AUTOBOT_IMPLEMENTATION_2026-09-14.md`.
