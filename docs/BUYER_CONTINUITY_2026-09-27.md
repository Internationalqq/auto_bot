# Продолжение работы с тендером и ответ на запрос адреса

Начало: AutoBot `183acd1`, CRM `548857c`; tracked CRM diff пустой.
Чужой checkpoint AutoBot и untracked-файлы сохраняются.

Поручение целиком:

1. Найти адрес объекта в документах Волги, ответить Ярстройтех76; автоматизировать
   такой ответ в существующем самостоятельном почтовом процессе.
2. Восстановить чтение входящих; выяснить состояние 69 старых обращений и
   исправить отсутствие понятного результата ручной отправки.
3. Сохранять текущую страницу/тендер/вкладку AutoBot при обновлении CRM.
4. Показать фактический прогресс анализа тендера, поднять недавно используемые
   тендеры наверх и показывать время последнего действия пользователя.

Почта: брать адрес только из документов конкретного тендера с сохранением
источника; не придумывать место разгрузки. Повторная обработка ответа не
создаёт повторного письма. Не повторять uncertain и не отправлять все старые
дубли только из-за их нахождения в архиве. Все действия/ошибки видимы в UI.
Автоматизация — в собственном worker, без Codex cron и без зависимости от GPT.

Навигация: проверять источник сообщений iframe и допустимый маршрут, не
сохранять произвольные внешние URL. Прогресс — по реальным обработанным
позициям, отдельно от подтверждённых цен. Фоновая проверка почты не считается
действием пользователя и не меняет порядок его тендеров.

Проверки: изолированные БД/данные, значимые тесты повторов и восстановления,
авторизации и входных данных; frontend-наборы и browser 390/768/1280.
Перед production — резерв, план для любых новых рабочих таблиц, откат;
после — версия ресурсов, сохранность смет/переписки, фактический ответ и
работающий самостоятельный процесс. Завершение пакета не завершает поручение.

## Решение и план выпуска

Подтверждено: контракт п. 6.3 и ООЗ (включая редакции 20.03.26) указывают
Рыбинск, ул. Волжская набережная, участок от ДС «Полет» до д. 4к1
по ул. Академика Губкина. Юридический адрес заказчика не используется.
Manual campaign 69fde313… остановлен: email electro-art.com не подтверждён.
69 — архив прошлых черновиков, не 69 ожидающих отправки писем.
Mail.ru показал пустую страницу при сохранённом AX-дереве; одно обновление
вкладки чтения восстановило интерфейс. Композер автоматически не обновляется.

Миграция только добавляющая: таблица buyer_followups в buyer_outbox.sqlite3
и отдельная tender_activity.sqlite3. Старые строки/суммы не переписываются.
Перед выпуском: остановить почтовый worker в свободном интервале, сделать
SQLite backup и копию отчётов, проверить старые хеши после активации. Новые
таблицы создаются идемпотентно. Затем worker может создать один новый outbound
для существующего вопроса Ярстройтех76. Это предусмотренное изменение данных.
Повторы защищены ключом входящего ответа и одной отправкой адреса на переписку.
Ответы старше 7 дней автоматически не инициируют письмо. Чужой sender, конфликт
адресов или отсутствие явно подписанного адреса в DOCX оставляют review.

Откат: прежний Docker image + прежние два файла CRM + копия Mac inbox-модуля.
Worker на время отката остановить. Историю отправленных писем и новые таблицы
сохранить: нельзя восстанавливать старую очередь поверх совершённой отправки.
При откате автоматики новые письма вручную не дублировать.

Прогресс Волги на копии: проанализировано 214/259; подтверждённые цены 28
показываются отдельно. Список загружает подробные счётчики только для видимых
карточек. Активность сохраняется только при открытии и пользовательских
действиях, начальные отметки берутся из created_at поисков/ручных кампаний.
