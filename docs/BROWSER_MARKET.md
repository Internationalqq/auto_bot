# Поиск через обычный браузер без Hermes

## Поиск в каталогах без Авито — проверено 19 сентября

Наблюдаемый результат: web-задание само выбирает подключённые каталоги по материалу и региону, открывает их в Chromium, читает реальные ссылки на товары/прайсы и сохраняет только прошедшие общую проверку цены в точную позицию сметы. Профиль, Hermes, поисковый API и действия пользователя в Chrome не нужны. Начальный охват ограничен источниками из `autobot/supplier_catalogs.json`; новые регионы и категории добавляются после проверки публичного каталога. Общий HTTP-поиск сохраняется как дополнение, Google в Chromium остаётся выключенным.

Сохранить: границу региона, единицы и характеристики, отдельную доставку/налоги, условные цены как кандидатов, отмену, общий бюджет, срок наблюдения, lease и повторную публикацию, загруженные сметы. Стартовые адреса не являются подтверждением цены. Браузер читает до трёх подходящих сайтов и одного перехода по настоящей ссылке на каждом; формы и заказы не отправляет.

Приёмка: полный проход изолированная очередь → браузер → страница → сохранённая цена; отрицательные сценарии другого региона, несовпадающей марки, капчи, отмены и старого кеша; существующие проверки поиска/очереди и итоговый Python-набор. Живая проверка должна отличать доступную страницу от подтверждённой цены. Выпуск после результатов, резервной копии и проверки production.

Результат живой проверки с production-сервера, в отдельном контейнере без рабочих данных:

- М300, Ярославль: задача завершилась за 29,85 с; в тестовый Excel сохранено **6 700 ₽/м³** с `beton-yar.ru`. Доставка отдельно. Отдельная карточка того же сайта осталась кандидатом из-за слабого текстового совпадения; цена одного продавца не удваивает количество независимых источников.
- Гранитный щебень 20–40, Ярославль: выбран правильный каталог `samosval76.ru`, но подтверждённая цена не получена; ничего не включено в расчёт. Прежний запрос терял слово «гранитный» и выбирал гравийную фракцию; тип щебня теперь сохраняется.
- `yaroslavl-beton.ru` показал CAPTCHA. Отказ сохраняется на 30 минут в кеше страниц и отражается в примечании задания; следующая позиция не повторяет запрос немедленно.

Начальный реестр — **три сайта для Ярославля** (бетон/раствор и каталог нерудных материалов/техники), а не общий индекс интернета. Для другого региона эти сайты не подставляются: работает прежний HTTP-поиск с его ограничениями. В этот пакет не входят новые подтверждённые прайсы на работы и другие регионы. Адреса и темы редактируются в `autobot/supplier_catalogs.json`; поля реестра только выбирают каталог, доказательство региона берётся со страницы. `price_page: true` разрешает известную главную страницу с прайсом как прямой источник. Незарегистрированные главные страницы и поисковая выдача прежними проверками не допускаются.

Браузер сначала читает каталог и настоящую ссылку; карточка открывается в общем проверяющем цикле. Так обнаружение ссылок не тратит весь лимит на предварительное чтение товаров. Один снимок используется в проверке цены, дата снимка при повторном чтении не обновляется. Изменение реестра меняет ключ кеша выдачи. Google не включён; живая проверка также подтвердила CAPTCHA Яндекса/DuckDuckGo/Brave, блокировку Startpage и нерелевантный Bing. В отдельном headless Chrome на ПК Google тоже показал CAPTCHA: доступ интерактивной вкладки Codex не переносится на другой браузер автоматически.

Обычные `research_item`, `research_position_market`, полный проход тендера и CLI по умолчанию используют `web`; web-режим получает WebBrowserFetcher независимо от выключателя Авито. Явный отдельный режим Авито сохранён, но сам не добавляется при пустом web-результате. В production Compose обычный поиск также настроен на `web`, чтобы прежняя переменная окружения не включала Авито обратно.

Итог: **842 passed, 2 skipped, 20 subtests passed**, 137,35 с, изолированная Windows-копия без сети. Node `tests/research_frontend_tests.js` прошёл. Проверены несовпадающие регион/марка/тип щебня, таблица нескольких цен, отсутствие запросов Авито, отмена до следующей навигации, сохранение времени кеша, пауза CAPTCHA, реальная публикация через очередь и отсутствие повторной записи после завершения. Самопроверка diff выполнена; независимого ревью и полного набора CRM/Linux не было. HTML/CSS/JS и раскладка не менялись, проверки 390/768/1280 повторно не запускались. Рабочие данные не мигрируются; стоимость доставки, накладных, резерва и налогов остаётся условием конкретного тендера.

Переключатели текущего пакета: `MARKET_BROWSER_CATALOGS=1` включает каталоги; `0` возвращает прежнее обнаружение. `MARKET_WEB_BROWSER=0` выключает весь web-браузер. `MARKET_BROWSER_DISCOVERY=0` оставляет Google выключенным. Следующий шаг — расширять проверенный реестр по фактическим материалам и регионам смет, отдельно измеряя долю найденных и подтверждённых цен.

## Предыдущий пакет 19 сентября 2026: дозагрузка страниц

Наблюдаемый результат: существующая очередь web использует установленный Chromium для страниц поставщиков, которые не удалось прочитать или подтвердить через HTTP. Отдельный агент, Mac mini и LLM-ключ не нужны. При недоступности браузера остаётся прежний HTTP-поиск. Цены из выдачи остаются кандидатами до проверки конкретной страницы. Авито не добавляется в web-задания.

Сохранить: отмену и lease, восстановление принятого результата, идентичность строки и версии сметы, проверки единиц/региона/даты, отсутствие произвольных процентов в экономике. Рабочую очередь и checkpoint не преобразовывать.

Проверки до выпуска: существующие тесты поиска и очереди; новые проверки браузерного обнаружения, раздельного профиля, CAPTCHA/таймаута, отмены и передачи браузера в проверку источников; проба с серверного адреса без рабочих смет и очередей; проверка текущей production-версии и отката. Начальная проверка затронутого участка: 45 passed.

## Живая проба в браузере этого ПК

19 сентября через обычные страницы Google, Авито и поставщиков:

- Google по «бетон М300 Ярославль цена м3» нашёл прямые сайты. Авито по тому же товару открыл выдачу с 25 объявлениями, хотя первая навигация сначала превысила время ожидания. Это не доказательство блокировки.
- [Объявление Авито](https://www.avito.ru/yaroslavl/remont_i_stroitelstvo/beton_m300_8313664391): 3 900 ₽/м³, заголовок М300, характеристика М200/В15; итог зависит от марки, объёма и доставки. Для М300 в расчёт не брать.
- [БетонТоп](https://yaroslavl-beton.ru/tovarnyj/m300/): обычный щебень 6 750 ₽/м³; отдельно варианты с добавками 5 400/5 450 ₽/м³. Сайт предупреждает об ориентировочной стоимости. Минимум страницы не доказывает цену выбранного состава.
- [ШтеттерБетон](https://beton-yar.ru/): в таблице М300/В22,5 — 6 700 ₽/м³; доставка отдельно. Налоговую подпись сайта сохранять как условие источника, а не считать установленным режимом тендера.

Это узкая проверка одного материала в одном регионе, не приёмка всех категорий и не подтверждение доступности с серверного IP. Продавцам ничего не отправляли, заявки не создавали, CAPTCHA не проходили. Найденные предложения не записывались в рабочую смету.

## Проверка с сервера и принятое решение

В отдельном контейнере текущего production-образа, без его данных, секретов и очереди, проверены новые исходники:

- Google показал страницу защиты/CAPTCHA. Повторные попытки и обход не выполнялись.
- Обычная выдача Bing загрузилась, но на запрос М300/Ярославль вернула общие статьи о бетоне. Сам факт загрузки не принят за качественный поиск.
- Страница `beton-yar.ru` открылась в Chromium; существующий анализатор выбрал 6 700 ₽/м³ для М300/В22,5 из таблицы с 83 найденными ценовыми фрагментами. Это проверка извлечения одной публичной цены, не расчёт прибыли и не коммерческое предложение.

Поэтому браузерная дозагрузка поставщиков включена, а обнаружение через Google подготовлено как опция и **на production выключено**. Включать Google на серверном IP, где уже получена CAPTCHA, не нужно. Авито в браузере этого ПК доступно; круглосуточный Авито-исполнитель пока не установлен. API очереди пригоден для обычного браузерного исполнителя и больше не требует инструментов или машины Hermes.

| Настройка | По умолчанию | Назначение |
|---|---|---|
| `MARKET_WEB_BROWSER` | `1` | Ленивый Chromium в web-очереди; `0` возвращает прежний HTTP-путь |
| `MARKET_BROWSER_DISCOVERY` | `0` | Поиск Google через Chromium; включать только после живой проверки с того же адреса |
| `MARKET_SOURCE_BROWSER_FALLBACK` | `1` | Ранее существовавший переключатель дозагрузки страниц |

Каждая позиция получает отдельный временный контекст без личных cookies и профиля Авито. Сохраняются общие ограничения времени, страниц, запросов и отмены. CAPTCHA Google отключает дальнейшие попытки в текущей позиции и включает паузу 15 минут в процессе. Непрозрачные переходы Google `/goto` не угадываются; при отсутствии прямых ссылок используется прежний поиск. Кеш браузерной выдачи отделён от HTTP-выдачи.

В сохранённых данных идентификаторы `hermes-browser-agent` / `hermes-avito-agent` оставлены для совместимости обработчика. Это исторические значения адаптера, не требование установить Hermes. Тексты новых заданий и результатов используют «браузерный исполнитель».

Следующий отдельный результат для полной автоматизации Авито: обычный локальный браузерный исполнитель с claim/heartbeat/complete существующей очереди, проверкой доступности и явным статусом остановки. Успешная работа интерактивного браузера Codex не означает, что фоновый Chromium без этой сессии будет доступен. Проверять на нескольких материалах/работах и регионах; не объявлять подключение завершённым до реального прохода очередь → объявление → проверка → отчёт.
