# Один отдельный агент Автобота

Уточнение пользователя 26 сентября отменяет участие gulya и zakup_alibert.
Baseline: AutoBot 2c97fc5; чужой data/search_resume_checkpoint.json и
.impeccable/ сохраняются. CRM 1cf1cb6, tracked diff пустой.

Наблюдаемый результат: один выделенный профиль autobot-mail (закупщик Автобота),
один последовательный отправитель/читатель ответов. Подготовка обычных обращений
выполняется скриптом, без второго Hermes-профиля. Старый draft API выключается
только после проверки отсутствия незавершённых запусков; журнал сохраняется.
Служебное имя autobot-mail сохраняем для совместимости с существующими квитанциями.

Порядок:
1. Вынести существующий формат обращения в независимый от серверной БД модуль.
   Подключить шаблонный режим worker с прежним журналом и проверкой результата.
2. Отключить только добавленный нами desktop-queue в двух прежних профилях,
   сохранив их настройки и задачи; закрепить инструкции единственного закупщика.
3. Перевести подготовку на скрипт, остановить старый draft-only gateway.
   Проверить повтор, сохранность sent/uncertain и отсутствие второго AI-процесса.
4. Проверить единственного исполнителя через API без отправки новых писем.

Обязательные сохранения: цены сметы не выходят наружу; количество и единицы
не округляются; неопределённые объёмы не выдумываются; без повторной отправки
sent/uncertain; старые агенты не получают задания и не делегируют для Автобота.
Общий рабочий стол Mac остаётся общим: один профиль не означает отдельную ОС
или отдельную авторизацию браузера. Не обещать устранение всех конфликтов окон.

Проверки: затронутые Python-наборы на изолированной копии; подготовка без
создания HermesClient, повтор/потеря ACK, сохранение старых результатов,
прекращение переключения при незавершённом AI-задании. Проверка Mac services/API.

Локальная проверка: 88 тестов PASS (7 single-agent, 29 Hermes, 9 jobs,
22 workflow, 15 outbox, 6 campaigns). Изолированная временная копия, без
production-БД. Включены повтор после перезапуска, потеря ACK, запрет повторной
подготовки незавершённого AI-задания, неизвестные объёмы, сохранение reviewed
результата и точных составных единиц. Полный suite и UI не запускались.
