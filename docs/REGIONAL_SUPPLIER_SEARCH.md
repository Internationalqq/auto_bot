доставки, поэтому старая запись исключается из медианы без переписывания сметы.

Ограничения и следующий шаг:

- Учитывается введённый регион и доказательство с сайта. Сопоставление города с областью расширено пока для Ярославля и Рыбинска; для других регионов сохраняется буквальное подтверждение региона/доставки. Полного адресного справочника России пока нет.
- Контакт и коммерческая страница подтверждают происхождение найденной цены; юридическая проверка поставщика по реестрам не выполняется.
- Наличие опубликованного прайса не гарантирует складской остаток, доставку к сроку и финальную цену договора. Неизвестные расходы не заполняются процентами по умолчанию.
- Поиск ограничен временем/числом страниц, сохраняет частичный результат и не обходит CAPTCHA. Проверка всей сметы возможна существующей очередью; реальные цены по всем 127 строкам Волги не заявляются найденными. Пропуски исходного разбора/OCR остаются отдельной задачей.
- Следующий пакет приёмки — другие регионы и категории (работы, кабель, фасовки, ЖБИ), расширение справочника адресов и подготовка запросов КП для строк без публичной сопоставимой цены.
