## Результат и границы

Пользователь должен за несколько секунд увидеть позиции, цену сметы, медиану сопоставимых подтверждённых предложений, разницу и результат последнего поиска. Медиана уже рассчитывается сервером по подтверждённым ценам. Не менять критерии подтверждения и экономику ради заполнения таблицы. Пустое значение означает отсутствие подтверждения; кандидаты показываются отдельно с ценами и причинами. Разница за единицу — справочное сравнение, не прибыль. Цвет и SVG-иконки дополняют подписи, а не заменяют их.
