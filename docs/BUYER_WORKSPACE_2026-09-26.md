# Поставщики внутри тендера AutoBot

Уточнение пользователя 26 сентября: основной сценарий живёт в AutoBot, внутри
тендера. Машинные выгрузки остаются дополнительным способом забрать результат.
Существующий визуальный язык тендеров сохраняется (Operate); новая вкладка
«Поставщики» расширяет текущую страницу, отдельный продукт не создаётся.

Наблюдаемый результат: выбор строк сметы → вкладка «Поставщики» → один запуск
подбора → компании с контактами, позициями, ценами и состоянием обращения.
По умолчанию готовятся обращения; явно выбранный режим email включает отправку.
Компания раскрывается до позиций, текста, редактирования, отправки и переписки.
Фото берётся только из опубликованных метаданных источника; без него — инициалы.
Цена сайта и ответ поставщика различимы; неподтверждённые условия не становятся
подтверждённой рыночной ценой. Предыдущие подборы и обращения доступны отдельно.

Сохранить: URL/API, выделение строк, ручной адресат, исправление текста,
повтор только blocked, историю uncertain/sent, проверку ответов, роли и
проверку версии сметы. Рабочие данные не мигрируются и письма при QA не уходят.

Проверки: целевые backend и frontend наборы в изолированной копии, полный
тендер на контрольных данных 390/768/1280, переходы между вкладками,
фильтры/история, обновление во время редактирования, пустое и ошибочное состояния.
Перед выпуском — просмотр diff, кандидат Docker, резерв образа и проверка
публикации/отказа без авторизации. Результаты дополняются после проверки.

## Проверенный результат

- Отдельная вкладка `#suppliers`, общая область выбора сметы, один запуск с
  явным режимом подготовки или email. Компании показывают контакт, позиции,
  цену конкретной позиции, происхождение цены и состояние обращения.
- Фильтры «С ценами», «Ответили», «Нужно действие», поиск по компании/контакту/
  позиции. История подборов и текст/JSON доступны в дополнительном раскрытии.
  Старые обращения остаются доступны. Ссылка из строки сметы ведёт в переписку.
- Изображение из og:image/twitter:image источника: сохранена ссылка происхождения,
  загрузка через CRM-авторизацию и проверку принадлежности кандидата тендеру.
  Общая защита DNS/IP/redirect, размер до 2 MB, только JPEG/PNG/GIF/WebP с
  проверкой сигнатуры. Кеш ограничен 24 элементами. При недоступности — инициалы.
  Реально проверены HTML и JPEG Кабель.РФ, 22 000 байт, без отправки сообщений.
- При отсутствии названия сайта новый сбор использует домен вместо заголовка
  товара. Старые сохранённые названия не мигрировались.
- Версия сметы проверяется сервером; устаревший запрос также блокируется в
  интерфейсе. Фото/найденная цена не меняют экономику или подтверждённую цену.

Изолированная Windows-копия: 140 unittest (`test_buyer*.py`,
`test_hermes_buyer.py`) PASS. Новые проверки охватывают метаданные фото,
тип/сигнатуру, кеш, локальные сети, отказ без сессии и другой тендер,
связь компании с заданиями. Ошибка передачи supplier_id через auth-декоратор,
найденная первым прогоном, исправлена; итоговый прогон успешен.

Frontend PASS: buyer_frontend_tests, tender_workspace_frontend_tests,
tender_market_run_frontend_tests, tender_price_filters_frontend_tests.
Новые проверки: вкладка suppliers и явный delivery=email, защита повторного
клика. В полном тендере на изолированных данных проверены 390/768/1280,
переполнение отсутствует; фильтр цены, раскрытие, редактирование, фото,
выбор строки → запуск по её ключу, остановка, ошибка подключения и восстановление,
пустое состояние. При автообновлении изменившегося результата сохранены текст,
фокус и позиция курсора 31; устаревшие запросы disabled.

Независимый Impeccable finish-review: первоначально `fix` — цена компании
не называла позицию. Подпись добавлена; финальный verdict pass `ship`,
единственная правка `resolved`. Статический detector buyer.js/css: `[]`.
Отдельно выполнен просмотр diff на доступ, повторные отправки и сохранение
прежних сценариев. Полная тестовая база и новая живая переписка не запускались.

Выпуск объединён с отдельным пакетом общей навигации AutoBot. Основной пакет
поставщиков — `342d72d`, конечный опубликованный AutoBot —
`a511b0e956441a689c2629ae1d3a30040975842b`, CRM —
`dddb826292dc988bf4d93d78f71fbbe03ede9271`. Дополнительное исправление общей
навигации отдаёт CSS через существующий защищённый `/estimates` proxy.
Код Mac-почтового исполнителя не менялся.

Первый объединённый Linux smoke дал 139/140: фикстура маршрута в
`test_buyer_jobs.py` подменяла `sys.modules`, но не атрибут `autobot.web_ui`
после предварительного импорта приложения. Исправлена изоляция обоих путей
импорта; повторный прогон с предварительно загруженным настоящим `web_ui`
на изолированной Windows-копии — 140/140 PASS. Финальный Linux-кандидат
с предварительным импортом `web_ui` также прошёл 140/140. Изменение касается
только теста, контракт приложения не меняет.
