Connection error после capture, без клика отправки. AX-only проверка тоже
получила обрыв соединения. Причина связи не установлена.

Современная форма Mail.ru в Firefox не фиксировала ввод адресата; все проверки
поймали это до Send. Собственный испорченный черновик отменён. Через штатную
ссылку доступной версии открыта light.mail.ru с тем же входом. Обычные HTML-поля
корректно заполняются AXValue: отдельно проверены реальные значения, пустые
копии и полное тело, затем screenshot. Пароли/cookies не переносились,
защита драйвера не отключалась, новые агенты не создавались.

Реальная отправка выполнена скриптом, без AI. Mail.ru показал «Письмо отправлено»;
письмо открыто из «Отправленные» по совпадению строки получателя и темы.
Message URL: https://light.mail.ru/message/17904192240858699569/?folder=500000
Полный текст и адресат сверены. Ответ поставщика пока не получен.

Механизм: sender_mode=mailru_lite_script, один autobot-mail desktop lock.
После подготовки fsync-журнал записывается ДО Send. После потери подтверждения
повтор запуска только сверяет отправленные, никогда повторно не нажимает Send.
Сверка страницы проверяет sent folder, отправителя, адресата и полное тело.
Проверка списка пока ограничена первой страницей отправленных; основная защита
повторов — серверный outbox и сохранённый журнал, сомнительные старые попытки
не переотправляются. Пагинация/поиск старых писем — следующий отдельный пакет.

Добавлен защищённый reconcile_sent для владельца исходной lease: допускает
только финализированный uncertain → sent с точной прежней квитанцией и новым
доказательством. Сохраняет прежний результат в существующую таблицу истории;
схема БД и остальные записи не изменяются. Это не сброс и не разрешение повторов.

Проверки и выпуск: заполняется по результатам приёмки.
