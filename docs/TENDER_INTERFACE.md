# Каталог и следующее действие

Каталог показывает сохранённые закупки и технический этап обработки. «Есть сравнение» означает наличие файлов сравнения; это не подтверждение всех цен, полноты сметы или прибыльности участия. Старые ключи фильтров и поле `is_ready` сохранены для совместимости.

- Основное действие каталога — поиск по отдельному профилю. Добавление по ссылке или номеру раскрывается по запросу.
- «Фильтры каталога» относятся к уже сохранённым карточкам. Они не меняют условия нового поиска в ЕИС.
- Поиск, сортировка, фильтры закона/этапа/способа/цены/дат/региона, выбор нескольких карточек, экспорты, импорт в CRM и удаление в корзину сохранены.
- Заказчик, даты и наличие файлов раскрываются внутри карточки; скрытые данные участвуют в поиске. Пустое состояние работы не занимает место, ошибки и журнал остаются доступны.
- Журнал незавершённого скачивания или разбора имеет приоритет над старыми отчётами. Служебный download_log и временный входящий файл не считаются скачанным документом.

В открытой карточке действие выбирается по данным: сначала комплект документов, затем разбор, замечания и пропуски распознавания, недостающие подтверждённые цены, просмотр позиций. Архивная ошибка ведёт к повторному разбору. Ручной повтор поиска и выгрузки остаются в меню «Ещё». Наличие всех цен не создаёт вывод о прибыли; условия участия хранятся отдельно в CRM с прежними правами.

## Защищённые маршруты

Клиент использует пространства, которые действующий Nginx направляет в AutoBot с проверкой доступа CRM. Старые адреса сохраняются как алиасы внутри приложения; Nginx и права не расширяются.

| Действие | Адрес клиента | Старый алиас |
|---|---|---|
| Перечитать одну смету | `/api/reports/rebuild` | `/api/rebuild-report` |
| Перечитать все сметы | `/api/reports/rebuild-all` | `/api/rebuild-all-reports` |
| Размер хранилища | `/api/tenders/storage-overview` | `/api/storage-overview` |
| Выбор объекта CRM | `/api/tenders/crm/projects` | `/api/crm/projects` |
| Поиск отдельной позиции | `/research/items` | `/api/research-items` |
| Скрипт поиска позиции | `/research/client.js` | — |
| Доказательство цены | `/tenders/market-audit` | `/market-audit` |

Встроенный режим выбирает объект через существующий защищённый мост CRM. Прямая карточка использует прежний обработчик выбора объекта. Проверка источника POST-запроса, разрешённые роли и отдельная авторизация исполнителя сохраняются.

Скрипт поиска позиции вынесен из строки Python в `static/research.js`: пример с несколькими строками больше не ломает JavaScript всей страницы. Повтор Ctrl+Enter не создаёт параллельный запрос. Текст источников вставляется как текст, ссылки допускают только HTTP/HTTPS; неподтверждённая цена не показывается как принятая в расчёт. Поведение проверяет `node tests/research_frontend_tests.js`.

Проверки поведения находятся в `tests/test_tender_next_action.py` и существующих наборах загрузки, разбора, каталога, карточки и CRM-моста. Реальная проверка Nginx на изолированных upstream выполняется из CRM: `tests/nginx_autobot_access_probe.py`.
