# Поиск и проверка рыночных цен

Одиночный поиск и поиск по смете используют один цикл `_research_row_market`: доступный индекс → варианты запроса → разные страницы источников → проверка → сохранение частичного результата. По смете дополнительно проверяются количество, цена, сумма и принадлежность строки. Ни модель, ни сниппет поисковика сами по себе не являются подтверждением цены.

Поиск сначала получает более широкий список кандидатов, затем открывает страницы. По умолчанию — до 12 разных ссылок и 3 вариантов запроса, цель — 3 независимых источника. Повторная ссылка в другом варианте запроса не открывается заново. Несколько страниц одного продавца не завершают поиск как три независимые цены. Отображаемое число предложений не ограничивает глубину выдачи до проверки.

Основные бесплатные источники обнаружения: Bing и DDGS с отдельными вызовами Яндекса и Startpage. SearX используется только при заданном адресе. Поставщик или подрядчик остаётся источником самой цены. Все варианты сохраняют регион; простой запрос дополнен точным запросом и поиском поставщика. Проверка использует исходную позицию. Текущий список поддерживаемых движков указан в [документации DDGS](https://github.com/deedy5/ddgs/blob/main/README.md); доступность каждого проверяется живым запуском, а не предполагается по наличию библиотеки.

На странице выбирается подходящая точная цена; рекламная цена «от» остаётся кандидатом. Тариф за объём и расстояние не превращается в стоимость кубометра материала. Сохраняются проверки даты, единицы, спецификации, региона и независимости источников из `market_evidence_policy` / `market_contract`.

| Настройка | По умолчанию | Допустимый диапазон |
|---|---:|---:|
| `MARKET_POSITION_MAX_PAGES` | 12 | 1–40 |
| `MARKET_POSITION_MAX_QUERIES` | 3 | 1–4 |
| `MARKET_POSITION_TIMEOUT_SEC` | 90 с | 10–300 с |
| `MARKET_INDEX_MIN_SOURCES` | 3 | 1–10, не больше числа выдаваемых цен |
| `MARKET_SEARCH_BACKENDS` | `yandex,startpage,brave,mojeek` | Существующие движки DDGS |
| `MARKET_SEARCH_BACKEND_LIMIT` | 2 | 1–4 |
| `MARKET_EMPTY_CACHE_TTL_SEC` | 180 с | 30–900 с |

Срок ограничивает начало новых операций, уменьшает оставшийся HTTP/браузерный таймаут. Уже начатая операция библиотеки или браузера завершается по собственному таймауту; это не жёсткий лимит всего процесса. Остановка по лимиту сохраняет полученные предложения и пояснение. Лимиты позиции и оставшиеся пробелы записываются в диагностический журнал.

Кеш выдачи хранит запрошенную глубину. Более глубокий поиск обновляет старую короткую выдачу; пустой результат быстро устаревает. Кеш страниц, свежесть цены и поисковая выдача имеют разные сроки. Отрицательные результаты и цена без регионального доказательства не становятся подтверждёнными из-за повторного чтения кеша.

Авито остаётся отдельным ограниченным резервом при отсутствии подтверждённых web-цен. Пауза после блокировки, суточный лимит и бережный режим сохранены. Этот пакет не устанавливает внешний браузерный исполнитель и не добавляет платный API.
