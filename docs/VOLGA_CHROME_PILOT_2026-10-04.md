# Пилот поиска Иваном через Chrome

Поручение пользователя 4 октября: использовать существующего Ивана (Hermes,
профиль commercial) на Mac mini, только Google Chrome. Firefox и Safari не
трогать. Это разовый ограниченный пилот, не постоянная автоматизация.

## Исходное состояние

AutoBot 0f8ff95; чужие data/search_resume_checkpoint.json и .impeccable/ сохранены.
Волга 0171200001926000664: 40/213 сопоставимых цен. Выбраны 10 незакрытых
товарных строк из текущей сметы, исходный snapshot с position_key сохранён.
Действующая модель Ивана gpt-6-astra, reasoning medium не изменялась.

## Граница и проверки

Пять свежих сессий по две позиции; максимум 24 итерации и 210 секунд на пакет,
общая граница 900 секунд. Максимум две Google-попытки и три карточки на строку.
Только computer_use и file; без почты, отправок, заказов, делегирования и расписания.
Общий browser_lock берёт управляющий скрипт, освобождает только свой ticket
после завершения собственного процесса. Чужие браузеры/процессы не останавливаются.
Явный отказ инструмента или CAPTCHA останавливают пакет и весь пилот.

Профиль commercial имел устаревшее allowed_apps=[Safari]. По новому поручению
список заменён на [Google Chrome], актуальное правило внесено в SOUL.md и как
исключение в общий README. Остальные профили не менялись. Резерв на Mac:
/Users/egor/.hermes/profiles/commercial/workspace/chrome-pilot-backup-20261004-132427.

Первый запуск за 34 секунды обнаружил отсутствие computer_use в наборе: SSH
PATH не включал ~/.local/bin с уже установленным cua-driver. Действий в
браузере не было. Результат сохранён в preflight-batch-1, окружение запуска
исправлено; установка/обновление драйвера не выполнялись. Доступен v0.28.2.

## Продолжение после подтверждения пользователя

На конкретный запрос разрешить ввод и клики только в Chrome для ограниченного
пилота пользователь ответил «ну делай что сделать надо?». Для этих запусков
добавлен локальный callback, который выдаёт `approve_once` только для разрешённых
действий Chrome, до истечения 900 секунд. Глобальное автоодобрение не включено,
ядро Hermes и его проверки запрещённых действий не менялись. Сохраняется аудит
действий; другие приложения, опасные сочетания и почтовые URL отклоняются.
Девять проверок ограничений callback прошли. В первой версии обёртки ошибочно
возвращался CLI-вердикт `once` вместо контракта `approve_once`; исправлено после
сверки с установленным CLI. Ошибочный запуск сохранён в callback-format-batch-1.

После исправления разрешений обнаружена отдельная проблема фонового ввода:
драйвер сообщал успешный type/return, но Google не открывался. Повтор с явным
cmd+l, затем с click адресной строки дал тот же результат: URL виден как текст,
вкладка остаётся новой. Артефакты navigation-batch-1 и background-keyboard-batch-1
содержат ноль предложений, собственные блокировки освобождены.

Установленный backend поддерживает `computer_use.keyboard_delivery_mode`:
для commercial включён `foreground`, с сохранением точного window_id, проверкой
окна драйвером и восстановлением фокуса. Резерв config-before-chrome-keyboard.yaml
лежит в каталоге пилота на Mac. Это проверка доставки клавиш в разрешённый Chrome,
а не обход отклонённого действия. Другие профили и шлюзы не перезапускались.

Foreground-ввод действительно открыл Google. Следующий capture выбирал Chrome
AXHelpTag: безымянную полоску URL 1640×22 вместо основной страницы 1920×975.
Это подтверждено отдельным read-only осмотром окон под browser_lock. Только в
процессе пилота добавлена узкая обработка: пустое дерево, безымянный Chrome,
высота screenshot <=32, ширина >=400; следующая свежая структура обязана
содержать и AXHelpTag, и AXWindow Google Chrome. Неизвестные окна не пропускаются.
Пять проверок распознавания прошли. Общий backend других профилей не изменён.

Первые пакеты открыли Google для ИБП, БОН, TRASSIR, SFP и коннектора. ИБП в
выдаче заменяется другим артикулом; это не принимается как совпадение. cmoshop

SSL timeout. Системный HTTP-прокси не включён; Karing disconnected, Tailscale
