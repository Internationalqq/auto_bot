# Минимальный список отправок

Исходный AutoBot `13cfd29`, production UI `fd5dc8d`; CRM `741466b`.
Изменение checkpoint и untracked-файлы сохранены. Этап — уточнение существующего
интерфейса по выбранной пользователем таблице, без изменений почтового скрипта.

Наблюдаемый результат: три колонки «Кому / Отправлено / Ответ», фактический
адресат, прошедшее время и короткий статус. Подробности письма и позиций
доступны в раскрытии строки. Повторяющиеся ошибки проверки заменяются общей
заметкой; отсутствие сохранённого ответа при ошибке не называется ожиданием.

Время считается только от подтверждённой отправки, обновляется независимо от
изменений API, без пересоздания строки и потери фокуса. Точная дата доступна
в подсказке. Неопределённые отправки сохраняют свой статус, время создания
не выдаётся за время отправки. Сохраняются цены, фильтры, поиск, отправка,
журнал, ограничения повторов и разделение переписки по фактическому адресату.

Проверка: поведенческие frontend-наборы (время, статусы, обновление без
перерисовки), браузер на копии данных 390/768/1280, раскрытие ответа,
длинные адреса и фильтры. Самопроверка diff, резерв и проверка production.
Миграции данных и новые письма не входят в этот пакет.

Реализовано: убраны изображения, состав сметы, повторы статуса отправки,
количества обращений и фрагменты ответов из свёрнутой строки. Текст ответа,
состав запроса, журнал и действия остаются внутри. Цены с оговорками сохранены.
Время обновляется каждые 15 секунд и при возвращении на вкладку, включая
неизменный ответ API и ошибку соединения; письмо проверяется прежним скриптом.
