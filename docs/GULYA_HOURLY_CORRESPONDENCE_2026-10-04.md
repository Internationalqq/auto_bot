# Ежечасная проверка ответов Гулей

Поручение пользователя 4 октября 2026: отдельная задача Гуле — каждый час
проверять почту/мессенджеры, отвечать поставщикам и сообщать о результате.

Настроено в существующем Hermes на Mac mini, профиль gulya. Это задача штатного
планировщика Hermes, не автоматизация Codex и не процесс на VPS.

- Job: `5d2dbdf7247f`, «Гуля — ответы поставщиков каждый час», enabled.
- Период: 60 минут; новая сессия на каждый запуск, attach_to_session=false.
- Отчёт: существующий личный Telegram-чат Егора через бота Гули.
- Инструменты: terminal, file, computer_use; браузер только Firefox.
- Полный текст и состояние: `/Users/egor/.hermes/profiles/gulya/workspace/hourly-correspondence/`.
- В этой папке сохранена резервная копия jobs.json до изменения.
- Прежние приостановленные задачи не включались; модель Гули не менялась.

В задаче определены: проверка рабочих аккаунтов, общий browser_lock,
обработка текущих переписок без новых рассылок, ответы только по подтверждённым
данным, запрет передавать телефон покупателя/обещать заказ или оплату.
Предусмотрены записи pending/sent_verified/send_unknown и проверка истории перед
повторной отправкой. Состояние и отчёты сохраняются между свежими сессиями.
Ограничение 15 минут/10 диалогов является инструкцией агенту, не отдельным
жёстким таймером процесса. Доступность каждого мессенджера проверяется в UI.

## Уточнение: все рабочие каналы, начиная с Авито

Пользователь сообщил о новых ответах на Авито и отдельно потребовал WhatsApp
и остальные каналы. В существующей задаче уточнён приоритет: Авито, WhatsApp
Web, Mail.ru, рабочий Telegram, MAX при наличии рабочей сессии. Сначала обзор
всех каналов, затем обработка порциями; лимит десяти ответов не разрешает
пропускать остальные каналы. Для каждого канала обязательны время и результат
или точный blocker. Обрабатываются действующие рабочие переписки по всем
объектам Гули, включая уже прочитанные человеком ответы, без смешения объектов.
