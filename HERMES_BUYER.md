# Hermes-закупщик: первый пакет

25 сентября 2026. Модуль `autobot.hermes_buyer` готовит только черновики запросов.
Он пока **не подключён к сайту, не ищет цены и не отправляет сообщения**.
Боевой Hermes не проверен: Mac доступен по сети, но SSH-вход с рабочего ПК отклонён.

Целевой сценарий: кнопка анализа на сайте → серверная очередь → исполнитель на
Mac → поиск по направлениям и региону → черновики обращений → выбор адресатов
и разрешение отправки → ответы поставщиков → проверка предложения и цены.
Существующие аккаунты остаются на Mac; сервер не получает их пароли.
Mac должен сам забирать задания по HTTPS, без публичного открытия Hermes API.

## Что работает в первом пакете

- Снимок до 100 позиций с исходными идентификаторами, количеством, единицами,
  направлением, типом, связью с родительской работой, регионом и условиями.
- Отдельный SQLite-журнал; одинаковый снимок возвращает то же задание.
- HTTP-клиент для `/p/autobot-buyer`, bearer-ключ только из окружения.
- Предварительная проверка: у профиля отключены инструменты. Пустой список
  инструментов нужен именно для первого теста черновиков; это ещё не поиск.
- Сохранение run_id и последующее чтение результата после перезапуска.
- Неопределённая отправка остаётся `submission_uncertain`: автоматического
  повторного POST нет, даже если экземпляр Hermes не поддерживает Idempotency-Key.
  Разбор такого состояния пока ручной; не удалять журнал ради повтора.
- Ответ проверяется по точному набору позиций; неизвестные или пропущенные
  позиции отклоняются. Результат `draft_ready` не попадает в каталог цен.

Это структурная проверка, не доказательство правильности текста черновика.
Пользователь должен проверить условия перед будущей отправкой. Механизма
отправки в этом модуле нет. Адрес профиля фиксируется при запуске; смена
адреса не перенаправляет чтение задания другому исполнителю.

## Локальная проверка на Mac после настройки профиля

Запускать из репозитория AutoBot с установленным `requests`. В окружении нужны
`HERMES_BUYER_URL=http://127.0.0.1:8642/p/autobot-buyer` и отдельный
`HERMES_BUYER_KEY`; ключ не передавать в командной строке или переписке.
Путь журнала выбирает оператор, вне Git, с доступом только владельцу.

```sh
python -m autobot.hermes_buyer check --db "$HOME/.hermes/autobot-buyer-journal.sqlite3"
python -m autobot.hermes_buyer enqueue --db "$HOME/.hermes/autobot-buyer-journal.sqlite3" --input example.json
python -m autobot.hermes_buyer advance --db "$HOME/.hermes/autobot-buyer-journal.sqlite3" --job-id ID
python -m autobot.hermes_buyer show --db "$HOME/.hermes/autobot-buyer-journal.sqlite3" --job-id ID
```

`advance` делает один шаг: запуск или получение статуса. Ожидание/планировщик
и серверный обмен ещё не реализованы. Для рабочего Mac сначала сверить API
установленной версии: [официальная документация](https://hermes-agent.nousresearch.com/docs/user-guide/features/api-server).

## Следующие пакеты и критерии готовности

1. Настроить отдельный профиль на Mac, проверить установленный контракт,
   выполнить живой тест только на синтетической смете.
2. Очередь на сервере + авторизованный исходящий исполнитель Mac: leases,
   heartbeat, восстановление и подтверждение приёма результата. Отдельный
   ключ исполнителя, никаких ключей Hermes в браузере.
3. Встроить запуск в существующую карточку тендера и загруженную смету:
   направления, регион, этапы, недоступный исполнитель, отмена, черновики.
   Сохранить текущий поиск; проверить доступ и 390/768/1280 px.
4. Подключить разрешённые средства чтения сайтов, контакты поставщиков,
   подготовку региональных запросов. Сверить реальные возможности каналов.
5. Реализовать отправку выбранным адресатам после согласования; постоянные
   идентификаторы сообщений и ответов, исключение повторов, лимиты каналов.
6. Сохранение ответов как исходных предложений; проверка единиц, количества,
   региона, НДС, доставки и срока. Только затем публикация пригодной цены.

## Проверки

19 целевых unittest проходят на изолированной копии (Windows, Python 3.11).
Включён HTTP-сервер-заглушка: запрос, bearer, Idempotency-Key, run_id,
перезапуск журнала и чтение готового черновика. Проверены параллельное
создание, изменение количества, неизвестные условия, сбои, неверный ответ,
смена адреса и блокировка включённых инструментов. Реальные Hermes/модель,
отправка, frontend, production и общий набор AutoBot не проверялись.
Первый запуск тестов системным Python не стартовал из-за отсутствия requests;
проверки выполнены другим установленным Python с этой зависимостью.
